Validation

Validate проверяет черновик. Save сохраняет ревизию. Apply переключает runtime.

    Rooms

    Aliases — отдельные слова во всех нужных формах. Locations — полные фразы, например «в ванной». Склонения автоматически не создаются.

    Devices / Targets

    Для каждой комнаты требуется ровно один light target с одной brightness capability. Сначала заполните комнату, затем назначьте устройство.

    Capabilities / Actions

    Доступны зарегистрированные операции света и входной двери. Диапазон яркости задаётся для action; отдельный action позволяет задать диапазон отдельного устройства.

    Entrance Door

    Только явное открытие входной двери. Эта политика и проверки противоречий света не редактируются. ID исходного M4 domain закреплены schema v1; новые комнаты/свет можно добавлять и удалять. Disabled/deny-policy пока не поддерживается этим runtime и отклоняется при проверке.

    Test Command

    Используется активная конфигурация и production CommandEngine. Оборудование не выполняет действия.

    

    Ревизии и восстановление
    Restore сохраняет выбранный backup как новую ревизию; затем нужен Apply. Удалённые стабильные ID нельзя повторно использовать.
