    Зоны и места
    



    

    Создавайте помещения, участки, линии и другие зоны. Группа зон объединяет дочерние места.
    

    

    

    

    

    

    

    

    Устройства
    


    

    Выберите готовый набор возможностей или создайте свои действия. Подключение к оборудованию настраивается отдельно и применяется через Save → Apply.
    

    

    

    

    

    

    Что умеют устройства
    



    

    

    

    Правила безопасности обязательны: открытие только явно указанной входной двери; противоречивые команды отклоняются. Эти правила не редактируются конфигурацией или ИИ.
    

    

    

    Command Playground
    

    
Проверить / Preview — понять команду без изменения устройства. Выполнить / Execute — изменить состояние виртуального устройства.
